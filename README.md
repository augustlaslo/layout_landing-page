# Nothing — лендінг

Моя навчальна робота в Mate Academy. Це односторінковий сайт бренду техніки
Nothing: велика картинка на весь екран, три товари, каталог за категоріями,
блок «про нас» і форма зворотного звʼязку.

Сайт зроблений **без JavaScript** — тільки HTML і CSS. Меню, плавний скрол
і поява блоків при прокрутці працюють на чистому CSS.

Верстав під три розміри екрана: 320px (телефон), 744px (планшет) і 1260px
(компʼютер).

## Що використав

- HTML — семантичні теги, методологія BEM
- SCSS — змінні, міксини, вкладеність, файл на кожен блок
- CSS Grid — сітка на 2 / 6 / 12 колонок
- Flexbox — розкладка всередині блоків
- Vite — збірка проєкту
- Stylelint і Prettier — щоб код був охайний

Картинки перевів у формат WebP і стиснув, щоб сторінка вантажилась швидше.

## Що вийшло зробити без JS

- меню відкривається і закривається через `:target`
- сторінка не скролиться, поки відкрите меню — `:has()`
- плавний перехід до секцій — `scroll-behavior: smooth`
- блоки виїжджають при прокрутці — `animation-timeline: view()`
- картинки збільшуються при наведенні — `transform: scale()`

Швидкість усіх анімацій задав однією змінною, щоб усюди була однакова.

## Як запустити

Потрібен Node.js.

```bash
npm install     # встановити все потрібне
npm start       # запустити, відкрити http://localhost:5173/
npm run lint    # перевірити код
npm run build   # зібрати
npm run deploy  # викласти на GitHub Pages
```

Важливо: перед `npm run deploy` треба спочатку зробити `npm run build`,
інакше на сайт піде стара версія — з цим уже були проблеми в попередніх
завданнях.

## Структура

```
index.html
src/
  images/            картинки та іконки
  styles/
    main.scss        головний файл, підключає решту
    utils/           змінні та міксини
    blocks/          по файлу на кожен блок
```
